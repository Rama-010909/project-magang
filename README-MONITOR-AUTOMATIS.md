# Monitor otomatis tanpa membuka JALANKAN-MONITOR.bat

1. Extract folder ini ke lokasi tetap, jangan dipindah setelah pemasangan.
2. Jalankan `PASANG-MONITOR-AUTOMATIS.bat` satu kali.
3. Setelah berhasil, monitor berjalan di background setiap kali Windows login.
4. Tidak perlu membuka `JALANKAN-MONITOR.bat` lagi.
5. Jika ingin melepas auto-start, jalankan `LEPAS-MONITOR-AUTOMATIS.bat`.

Monitor tetap harus dijalankan pada PC yang berada di jaringan LAN yang sama dengan perangkat yang dipantau. Website/Vercel tidak dapat melakukan ping langsung ke perangkat LAN privat.
